# 车载平衡滚球运动控制系统 · 设计报告资料

2019 全国大学生电子设计竞赛 H 题设计报告的**自行撰写部分**。纯文档仓库（Markdown / CSV），不含代码、不绑定硬件；报告正文与写作骨架就是本仓库的核心内容，配合其它硬件仓库的实测数据填写。

## 这份资料包含什么

- 按评分点反推的报告总纲与 8 页页数预算、三人分工与交接清单。
- 可直接往下填的正文骨架（摘要、方案论证、理论分析、硬件 / 软件设计、测试结果），以及整机测试记录 CSV 模板。
- 小车整体设计的硬件模块划分、器件清单与选型说明。

## 怎么用

1. **克隆或下载**本仓库，用任意 Markdown 编辑器 / Typora / VS Code 打开，无需安装任何环境。
2. **按顺序读**：`00_报告总纲与页数预算.md` 定结构 → `01_三人协作与交接清单.md` 分任务 → `03_设计报告正文骨架.md` 写正文 → `04_整机测试记录模板.csv` 填实测数据。
3. **填 `【待补】`**：骨架里所有 `【待补：…】` 必须用实物、代码或测试数据确认后替换，提交前删除全部提示文字；不要填写未完成的指标。
4. **排版基线**：正文 A4 纸 8 页以内、另附 300 字以内中文摘要、小四号宋体、固定 22 磅行距、页上方留 3 cm 空白、右下角页码；全文不得出现学校、队伍代码与姓名。赛区若另发通知以新通知为准。
5. **数据从硬件仓库来**：钢球定位与图传实测参见 `canmv-k230-vision` / `rk3576-k7c-vision`，循迹与 UART 协议参见 `omv-rt5-openmv-vision`。
