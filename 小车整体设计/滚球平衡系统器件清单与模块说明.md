# 滚球平衡系统器件清单与模块说明

> 文档基线：2026-08-01，当前工程运行模式为 `TEST_MODE_TASK4_V2`。
>
> 本文描述当前采用 K230 视觉反馈和 Emm V5 步进电机位置控制的滚球平衡系统。工程中保留的 QD4310、ICM42688 等旧方案不属于当前 Task4 V2 控制链路。

## 1. 系统功能概述

系统通过改变单自由度摆杆的倾角，使钢球沿摆杆轴向运动并保持在中心位置。摆杆中心定义为 `0 mm`，平衡时电机机械角定义为 `0°`。

K230 摄像头负责识别钢球，计算钢球相对中心的位置和轴向速度；STM32F407 接收视觉数据，在 TIM13 提供的 1000 Hz 节拍下执行位置 PID 和速度负反馈；控制结果以绝对位置脉冲命令发送给 Emm V5 闭环步进驱动器。驱动器控制步进电机，经曲柄连杆机构改变摆杆倾角，形成视觉闭环。

```text
钢球运动
   ↓
K230视觉检测 → 位置/速度串口帧 → STM32控制器
                                      ↓
                          位置PID + 速度负反馈
                                      ↓
                           绝对位置脉冲命令
                                      ↓
                     Emm V5驱动器 → 步进电机
                                      ↓
                         曲柄连杆 → 摆杆倾角
                                      ↓
                                  钢球运动
```

## 3. 硬件模块说明

### 3.1 K230 视觉检测模块

K230 是钢球位置和速度的唯一反馈来源。当前参考程序使用灰度图像和水平扫描线检测钢球，主要过程如下：

1. 摄像头采集 `1280×720` 图像，并裁剪摆杆所在的窄条区域。
2. 检测处理使用 `640×67` 灰度图，降低运算量。
3. 通过水平扫描线的明暗边缘、局部对比度和跟踪状态确定钢球中心。
4. 以可设置的中心基准计算一维位置，中心右侧为正、左侧为负。
5. 当前标定采用钢球直径 `10 mm` 对应 `20 pixel`，即约 `0.5 mm/pixel`。
6. 使用当前坐标与十帧前坐标及实际时间差计算速度，单位为 `mm/s`。
7. 每个发送周期通过 UART 输出位置和速度。

K230 串口协议：

```text
检测到钢球：<position_mm>,<velocity_mmps>\r\n
示例：      35,-120\r\n

未检测到钢球：N,0\r\n
```

其中：

- `position_mm` 为钢球相对中心的一维有符号位置，单位 `mm`。
- `velocity_mmps` 为钢球轴向有符号速度，单位 `mm/s`。
- K230 与 STM32 使用 `115200 bit/s、8N1`。
- 参考程序配置为每个检测帧发送一次，名义相机帧率为 `60 FPS`。若实机运行的是约 `130 Hz` 的另一版视觉固件，应以实测串口帧率为准；STM32 接收协议不依赖固定帧率。

对应文件：[Reference/main.py](Reference/main.py)、[Hardware/K230_uart.c](Hardware/K230_uart.c)。

### 3.2 STM32 主控制模块

STM32F407VET6 是系统控制核心，主要功能包括：

- 通过 USART2 中断逐字节接收并解析 K230 ASCII 数据帧。
- 通过 TIM13 中断发布 1000 Hz 控制节拍。
- 在 `main` 前台执行位置 PID、钢球速度补偿和脉冲限幅。
- 将电机命令通过 USART1 DMA 发送给 Emm V5 驱动器。
- 读取 PC1 启动按键并刷新 OLED。

中断中只进行字节接收、观测发布和节拍计数，不在中断中计算 PID 或发送电机命令。这种结构能缩短中断占用时间，并保证当前控制路径只有一个电机命令写入者。

对应文件：[Core/Src/main.c](Core/Src/main.c)、[APP/task4_v2.c](APP/task4_v2.c)。

### 3.3 位置与速度控制模块

控制器以钢球中心 `0 cm` 为目标。位置进入死区后，位置误差按零处理；钢球仍有速度时，速度负反馈继续产生制动控制量。

```text
position_cm = position_mm × 0.1
velocity_cmps = velocity_mmps × 0.1

position_output = PID(target_cm - position_cm)
control_pulse = position_output - velocity_gain × velocity_cmps
```

速度补偿的符号与钢球速度相反：钢球向正坐标运动时，控制器产生使其向负坐标减速的摆杆动作；钢球已向中心运动时，速度项会减小位置控制力度，从而降低过冲。

最终控制量先执行对称脉冲限幅，再经过实机方向映射和机械角度限位。PID 和速度补偿只决定目标位置，不直接控制电机电流。

对应文件：[APP/task4_v2.c](APP/task4_v2.c)、[Hardware/PID.c](Hardware/PID.c)。

### 3.4 Emm V5驱动器与步进电机模块

当前 Task4 V2 使用 `Emm_V5_Pos_Control()` 发送位置命令：

- 驱动器地址：`1`。
- 控制模式：绝对位置模式。
- `clk` 参数：相对平衡零点的目标脉冲绝对值。
- 方向参数：根据目标脉冲正负选择 CW 或 CCW。
- 命令发送：USART1 TX DMA。
- 电机整步角：`1.8°`。
- 驱动器细分：`16`。
- 每圈脉冲数：`200×16=3200 pulse/rev`。
- 单脉冲角度：`360°/3200=0.1125°`。

当前软件不在初始化时发送电机复位或使能命令，假定驱动器始终保持使能，并已通过驱动器自身功能自动回到平衡零点。STM32 当前只发送目标，不读取电机实时位置；闭环位置跟踪由 Emm V5 驱动器内部完成。

对应文件：[Hardware/Emm_V5.c](Hardware/Emm_V5.c)。

### 3.5 摆杆和曲柄连杆模块

执行机构为单自由度摆杆。电机输出轴带动曲柄，曲柄通过刚性连杆推动摆杆端部升降，使摆杆绕固定轴承旋转。摆杆倾角改变后，重力沿杆方向产生分量，从而使钢球加速、减速或反向运动。

当前控制直接把电机零点作为摆杆平衡基准，不在 Task4 V2 中进行连杆几何反解。因此必须满足：

- 驱动器绝对位置 `0 pulse` 对应摆杆水平位置。
- 电机正负方向与软件中的方向定义一致。
- 机构在 `-20°~+30°` 软件范围内无干涉和卡滞。
- 机械硬限位应位于不会损坏连杆、电机和摆杆的位置。

### 3.6 OLED显示模块

OLED 为 `128×64` 点阵屏，使用 GPIO 模拟 I²C：

- `PE13`：SCL。
- `PE14`：SDA。
- 写地址：`0x78`。
- 刷新周期：`100 ms`。

Task4 V2 只显示 K230 最近发送的两项数据：

```text
P: 位置 mm
V: 速度 mm/s
```

未检测到钢球时显示 `---`，不显示 PID、电机角度或任务运行时间。

对应文件：[Hardware/oled.c](Hardware/oled.c)、[Hardware/oled.h](Hardware/oled.h)。

### 3.7 启动按键模块

PC1 配置为内部上拉输入，按键另一端接地，因此：

- 松开：高电平。
- 按下：低电平。
- 按下并释放完成后，Task4 V2 才进入闭环控制。

按键驱动包含简单的按下和释放消抖。对应文件：[Hardware/key.c](Hardware/key.c)。

## 4. 接口与引脚分配

| 模块 | STM32 外设 | STM32 引脚 | 参数 | 说明 |
|---|---|---|---|---|
| Emm V5 驱动器 | USART1 | PA9/TX、PA10/RX | 115200 bit/s，8N1；TX使用DMA | 当前控制主要使用STM32 TX发送位置命令 |
| K230 视觉模块 | USART2 | PA2/TX、PA3/RX | 115200 bit/s，8N1；RX中断 | K230 TX接STM32 PA3，双方必须共地 |
| OLED | GPIO软件I²C | PE13/SCL、PE14/SDA | 地址 `0x78` | 当前驱动为GPIO模拟时序，不占用硬件I²C外设 |
| 启动按键 | GPIO输入 | PC1 | 内部上拉，低电平有效 | 按键另一端接GND |
| 控制节拍 | TIM13 | 无外部引脚 | 1000 Hz | 84 MHz定时器时钟，PSC=839，ARR=99 |
| SWD下载 | SWD | 按主控板SWD接口 | ST-Link | 固件下载和调试 |

UART交叉连接原则：模块 TX 接对方 RX，模块 RX 接对方 TX。K230、STM32、OLED和电机驱动器的通信地必须可靠共地；电机功率回路应避免与视觉和MCU信号线形成较大的干扰环路。

## 7. 系统运行过程

1. STM32完成时钟、GPIO、DMA、USART和TIM13初始化。
2. Task4 V2初始化K230串口接收、位置PID和OLED，不主动复位或使能电机。
3. TIM13开始以1000 Hz产生中断，中断函数只累加控制节拍。
4. 操作人员按下并释放PC1，系统清除旧控制状态并进入闭环。
5. K230识别钢球并发送位置、速度；USART2中断解析后发布最新观测。
6. 主循环消费一个TIM13节拍，使用最新位置执行PID，并用最新速度进行制动补偿。
7. 合成控制量经过脉冲限幅、方向映射和机械限位后，通过USART1 DMA发送给Emm V5。
8. 驱动器控制步进电机到达绝对脉冲目标，连杆改变摆杆倾角。
9. OLED每100 ms显示一次K230位置和速度。
10. 收到`N,0`或完整坏帧时停止发送新电机目标并重置PID，驱动器保持上一绝对位置；重新检测到钢球后继续以中心为目标控制。

## 9. 装配与实机检查

上电前至少确认以下项目：

- 驱动器细分确实为16，与软件的3200 pulse/rev一致。
- 驱动器自动回零后的 `0 pulse` 确实对应摆杆水平。
- 手动缓慢检查 `-20°~+30°` 范围内连杆无卡滞、碰撞或越过死点。
- 电机转动正方向会使钢球向K230负坐标方向运动；若不一致，应停止测试并核对接线或方向参数。
- K230位置零点与摆杆物理中心一致，钢球直径像素标定准确。
- K230、STM32和驱动器控制接口共地，UART电平兼容。
- 电机电源容量满足启动和制动电流要求，MCU电源无明显压降。
- 首次闭环测试时人员远离连杆运动范围，并具备立即断电条件。
- 编译通过只代表软件接口正确，不能替代零点、方向、限位和机构安全的实机验证。
